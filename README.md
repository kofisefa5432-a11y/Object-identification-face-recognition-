
# Object Identification and Face Recognition

## Description
Face detection and recognition with YOLO (Ultralytics), trained on a custom dataset of images of myself.

## Dataset
Sample images taken at different angles, lighting conditions, and expressions, stored in Google Drive and annotated for training.

## Tools
- Python
- Ultralytics YOLO
- Google Drive
- GitHub
- Ollama (Llama 3.2 1B)
